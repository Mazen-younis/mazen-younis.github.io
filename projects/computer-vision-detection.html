Object detection: YOLOv8 vs Faster R-CNN

Two approaches. One dataset. A lesson in data quality.

ATTRIBUTION

Collaborative project with Mert Satici

Training and comparing one-stage and two-stage object detectors on five everyday desk-object classes, including dataset evolution, augmentation analysis and evaluation.
01 / THE CHALLENGE

The challenge

Real-world desk scenes are cluttered, and small objects can be difficult to detect. The project explored the effect of targeted data collection and augmentation on detection accuracy.

02 / THE APPROACH

The approach

Trained YOLOv8n across three dataset versions, then evaluated a Faster R-CNN model using a custom annotation converter and PyTorch dataset loader. Compared precision, recall, mAP and representative detections.

  • Five classes: bottle, cell phone, cup, laptop and mouse
  • Conversion from normalised YOLO labels to absolute bounding boxes
  • Model-level comparisons across mAP thresholds
  • Documented results, project poster and source code
03 / THE OUTCOME

The outcome

The non-augmented 120-image final dataset produced the best YOLOv8n mAP@50–95 (0.870). Brightness augmentation improved recall in an intermediate experiment but increased false positives; Faster R-CNN achieved 0.9952 mAP@50.

YOLOv8n achieved 0.870 mAP@50–95 in the reported final evaluation.
